## NSW TRS Prototype (`bsm-nnsw-trs/`)

Browser-based **Nigeria National Single Window – Time Release Study & Trade Performance Assurance** application.

Features:
- Executive Dashboard (end-to-end timeline, KPIs, bottleneck call-outs)
- Shipment Explorer with event timelines
- Port Comparison
- Agency Scorecards
- Anomaly Detection
- Executive Reports

### Deploy

Deploy the **`bsm-nnsw-trs/`** directory (not the repo root) to Netlify or Vercel.

- Netlify: set base directory / publish directory to `bsm-nnsw-trs`
- Or drag the `bsm-nnsw-trs` folder to [Netlify Drop](https://app.netlify.com/drop)
